# Hall

Hall is the liege's audience hall: herdr, forked from v0.9.0 and renamed, with every live reeve at the top level of the sidebar, its hands beneath it, a hand state on every hand and a waiting-on-you badge on every reeve. The liege types `hall` and it starts, detaches and reattaches exactly like herdr, with its own sessions, config and state, sharing nothing with the installed herdr.

Hall is a modified version of herdr (https://github.com/herdrdev/herdr), Apache-2.0: herdr's `LICENSE` is kept, [NOTICE](NOTICE) says so, and [MODIFICATIONS.md](MODIFICATIONS.md) lists every herdr file hall changes. Herdr's own instructions for agents are kept for reference at [docs/herdr/AGENTS.md](docs/herdr/AGENTS.md).

**Status: step 1 (fork and separate) built: herdr v0.9.0 merged at the root and separated from the installed herdr (own folders, binary `hall`, inbound `HALL_*` names, protocol 1022), and `scripts/live-check`. Step 2 (test setup on hall): `scripts/test-setup` runs the test reeves and hands in the hall session `hall-dev` and makes no herdr call ([docs/test-setup.md](docs/test-setup.md)). Step 3 (reeve tree): with a listing command configured (`[reeve] listing_command`, decision 49), the sidebar shows each test reeve with its hands beneath it, a mark per hand and a badge per reeve, other workspaces apart, a key walk through the tree and a key help line at the bottom. Step 4 (alerts): a reeve's reply or dialog and a hand's dialog ring herdr's sounds, a hand newly blocked, asking, idle or wedged rings hall's own from the listing, and each raises a highlight on the reeve's row (and the hand's) that shows muted too, with `[reeve] alert_focused_reply` letting a reeve's reply alert in its focused tab. Step 5 (go-live bridge), hall's side: hall reads reeve's listing at version 1 ([docs/listing.md](docs/listing.md)), showing only entries in hall; every pane gets `HALL_SOCKET_PATH`, `HALL_BIN_PATH` and `REEVE_BACKEND=hall` so a reeve started there uses reeve's hall backend; a hand's dialog rings once even before the listing names it; and the test setup can run reeve's own listing (`--listing reeve`). Reeve's side and the cut-over follow.**
